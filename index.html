AgentFlow — Budget-Aware Recovery for Local Coding Agents

Evaluated v2

Engineering intelligent agent workflows through structured orchestration, local LLM execution, and system-level failure recovery. Designed to address non-deterministic agent failures, token runaways, and incomplete code-repair outputs under local model constraints.

System Architecture Flow
User Task Input → Task Interpretation → Workflow Orchestration → Agent / Tool Execution (Ollama/Gemma) → JSON/Schema Result Validation → Final Verified Output
  • Failure-Guided Recovery: Engineered a local code-repair agent supporting single-shot, fixed-retry, and failure-guided policies with strict schema validation, incomplete-response rejection, and repeat-failure detection.
  • Budget & Execution Bounds: Implemented strict model/tool/test/time/token budgets with timeout REPLAN/STOP decisions and per-call audit telemetry.
  • Empirical Evaluation: Ran v2 held-out evaluation on 35 Python bug-fix tasks with 3 repetitions across 3 strategies (315 runs): strict resolution reached 21.9% for failure-guided/fixed-retry vs 5.7% for single-shot, with zero budget-violation cases.

LLM Infrastructure • Model Routing • Systems

OptiRoute — Intelligent LLM Proxy & Semantic Router

Infrastructure Concept

Open-source LLM proxy-router concept focused on optimizing agentic workflows through dynamic model selection, semantic caching, and autonomous context pruning to reduce operational cost and token latency.

Routing & Optimization Flow
Agent Request → Request Analysis → Semantic Cache Check → Dynamic Model Arbitrage → Autonomous Context Pruning → Provider Execution
  • Dynamic Model Arbitrage: Automatically dispatches sub-tasks to smaller models or frontier models based on prompt complexity, latency constraints, and cost budgets.
  • Semantic Caching: Identifies semantically identical or near-duplicate queries using vector embeddings to avoid redundant inference calls.
  • Autonomous Context Pruning: Filters noisy history and irrelevant system context prior to downstream forwarding.

99.98% Accuracy

High-precision network traffic classifier built to identify Botnet / ARES attack patterns under severe class imbalance conditions using the CICIDS2017 benchmark dataset.
